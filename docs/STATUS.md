## 1. 완료된 것

### 백엔드 API (`apps/api`, NestJS 11, `/api/v1`)

- **엔드포인트 213개**, Prisma 모델 46개, 마이그레이션 10개 (PostgreSQL 16 + PostGIS + pg_trgm).
- **로그인**: 카카오 · 네이버 · Google 소셜 로그인만 지원 (Apple 로그인 없음, SMS·휴대폰 인증 없음).
  고정 경로 `GET /api/v1/auth/oauth/{kakao|naver|google}/start`, `.../callback`. 서버 세션(Redis, httpOnly 쿠키),
  CSRF 방어(Origin 검사 + 토큰 헤더), 로그아웃·전체 기기 로그아웃, 약관 동의 기록, 회원 탈퇴(소프트 삭제 + 개인정보 정리 예약).
- **관리자 로그인**: 이메일 + 비밀번호(argon2id) + **OTP 2단계 인증 필수**, 짧은 세션, 선택적 IP 허용 목록,
  관리자 변경 작업 전부 감사 로그(누가·무엇을·변경 전/후·IP).
- **권한**: USER / AGENT / AGENCY_OWNER / OPERATOR / ADMIN / SUPER_ADMIN, 모든 자원에 소유권 검사.
- **매물·공동중개**: 물건(Property)과 매물(Listing) 분리, 한 매물에 여러 중개사무소 참여(대표 중개사무소 지정),
  **공인중개사법 제18조의2 표시·광고 명시사항 검증**(필수 항목이 빠지면 게시 불가, 항목별 한국어 오류),
  호수(ho)는 공개 응답에서 제외, 실매물 확인 기록, 조회수.
- **지도 검색**: 낮은 확대 = 읍면동 묶음, 중간 = 격자 묶음(ST_SnapToGrid), 높은 확대 = 단지/매물 마커.
  가격·면적·방/욕실·방향·층·준공년도·옵션 필터, 목록 정렬 6종, Redis 타일 캐시. (시드 데이터 기준 응답 수~수십 ms)
- **단지·실거래가**: 단지/평형 정보, 국토교통부 실거래가(아파트 매매·전월세) 월별 자동 동기화(멱등),
  평형별 최근 거래·월별 중앙값, "자주 찾는 단지" 순위.
- **중개사무소**: 가입 신청 → 서류 업로드(비공개 저장) → 관리자 승인/반려/정지 이력, 직원 초대,
  국가공간정보 중개업 조회 API로 등록번호 대조(키가 있을 때).
- **내놓기 / 구하기**: 지역 전체 또는 선택한 중개사무소에 공개, 중개사무소 제안(Proposal),
  요청자가 동의한 경우에만 연락처 공개, 상태 흐름, 앱 내 알림, 일일 등록 한도·요청 제한.
- **광고**: 배너 슬롯별 개수 제한, 기간 예약, 노출 순서, 지역/단지 타기팅, 노출·클릭 집계(Redis → 일별 통계),
  안전한 클릭 이동 주소 검사. 팝업("N일 동안 보지 않기", 대상 페이지). 공개 API는 현재 게시 중인 것만 캐시해서 제공.
- **기타**: 관심 매물·단지, 최근 본 매물, 허위매물 신고(처리 흐름 → 매물 숨김/중개사무소 경고), 공지, FAQ,
  지역 영상(YouTube), 사이트 정보(상호·대표·사업자등록번호 등), 약관 버전 관리 + 회원별 동의 기록.
- **미디어**: 로컬 디스크 업로드, webp 변환(썸네일/중간/큰 이미지), EXIF 제거, 파일 내용으로 형식 판별, 무작위 파일명.
- **백그라운드 작업(worker)**: 실거래가 동기화, 배너 통계 반영, 조회수 반영, 이미지 처리, 만료 매물·요청 정리,
  탈퇴 회원 개인정보 정리, 고아 파일 정리 (BullMQ, 반복 작업 한국 시간 기준).
- **운영 기본기**: 구조화 로그(요청 ID), `/api/v1/health`·`/api/v1/health/ready`(DB+Redis), 무중단 종료,
  helmet·CORS 허용 목록·본문 크기 제한·요청 제한, 오류 응답 형식 통일(코드 + 한국어 메시지),
  Swagger 문서(`SWAGGER_ENABLED=true`일 때만).

| **관리자 이메일** | 첫 최고 관리자 계정용 (`create-admin.sh`로 생성, 첫 로그인 때 OTP 앱 등록)                          |

### API 키 (서버의 `/srv/house/shared/.env`에 입력)

| 키                                               | 발급처                        | 용도 / 비고                                                                                          |
| ------------------------------------------------ | ----------------------------- | ---------------------------------------------------------------------------------------------------- |
| `KAKAO_CLIENT_ID`, `KAKAO_CLIENT_SECRET`         | developers.kakao.com          | 카카오 로그인 (REST API 키, Client Secret). 이메일·전화번호 동의항목은 비즈 앱 심사가 필요할 수 있음 |
| `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`         | developers.naver.com          | 네이버 로그인 (서비스 오픈 전 검수 신청 필요)                                                        |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`       | console.cloud.google.com      | Google 로그인 (OAuth 동의 화면 게시 필요)                                                            |
| `NAVER_MAP_CLIENT_ID`, `NAVER_MAP_CLIENT_SECRET` | 네이버 클라우드 플랫폼 → Maps | 지도 표시·주소 변환 (프론트 구현 단계에서 사용). 서비스 도메인 등록 필요                             |
| `DATA_GO_KR_SERVICE_KEY`                         | 공공데이터포털 data.go.kr     | 아래 3개 API를 각각 **활용 신청** 후 같은 인증키 사용 (일반 인증키 Decoding 값)                      |

`DATA_GO_KR_SERVICE_KEY`로 쓰는 API:

1. 국토교통부 아파트 매매 실거래가 상세 자료 (`RTMSDataSvcAptTradeDev`)
2. 국토교통부 아파트 전월세 실거래가 자료 (`RTMSDataSvcAptRent`)
3. 국가공간정보 부동산중개업 정보 조회 (`EstateBrkpgService`, 중개사무소 등록번호 대조)

각 로그인 콘솔에 등록할 Redirect URI (도메인만 바꿔서 그대로 등록):

```
https://example.com/api/v1/auth/oauth/kakao/callback
https://example.com/api/v1/auth/oauth/naver/callback
https://example.com/api/v1/auth/oauth/google/callback
```

- 쿠키 비밀값(`COOKIE_SECRET`), OTP 암호화 키(`TOTP_ENCRYPTION_KEY`), DB 비밀번호는 `install.sh`가 자동 생성합니다.
- **SMS 업체 키, Apple 키는 필요 없습니다** (Apple 로그인·SMS 발송 기능 없음).
- 키가 비어 있는 소셜 로그인은 자동으로 꺼집니다(로그인 버튼 목록 `GET /api/v1/auth/providers`에서 빠짐).

### 사이트에 표시할 사업자 정보 (관리자 → 사이트 설정)

상호, 대표자, 사업자등록번호, 통신판매업 신고번호, 사업장 주소, 개인정보보호책임자, 고객센터 연락처·이메일.
현재 시드에는 `(상호 입력)` 같은 자리 표시 값만 들어 있습니다.

### 약관 원문

이용약관 · 개인정보처리방침 · 위치기반서비스 이용약관 · 마케팅 수신 동의의 **실제 문구**(법률 검토 권장).
시드에는 견본 문구만 있으며, 관리자 화면(또는 API)에서 새 버전으로 등록하면 회원에게 재동의를 받습니다.
위치기반서비스를 제공하려면 방송통신위원회에 위치기반서비스사업 신고가 필요할 수 있습니다.

## 4. 알려진 제한 / 다음 단계

### 다음 단계 (우선순위 순)

1. **사용자 사이트(`apps/web`)와 관리자 화면(`apps/admin`) 구현** — 디자인 확정 후 진행.
   API·공용 스키마(`packages/shared`)는 준비되어 있어 화면만 붙이면 됩니다. 브랜드명은 아직 미정(자리 표시 "BRAND").
2. 실제 키를 넣고 스테이징에서 카카오·네이버·Google 로그인 전체 흐름을 실제 계정으로 확인
   (자동 테스트는 외부 서비스를 가짜 구현으로 대체해서 검증했습니다).
3. data.go.kr 키로 순천시 실거래가 첫 동기화 실행 및 단지 매칭 결과 확인 (관리자 → 단지 → 실거래가 동기화).
4. 공식 **법정동코드 목록** 반영 — 시드의 순천시 읍면동 코드(35개)는 견본 값입니다
   (`seed: 읍면동 codes are SAMPLE values` 경고). 출시 전 행정표준코드관리시스템의 공식 목록으로 교체하세요.
5. 실제 단지 데이터 입력 — 데모 시드(`pnpm db:seed:demo`)의 단지·중개사무소·매물·배너는 모두 **가상 데이터**입니다.
   운영 서버에는 데모 시드를 넣지 마세요(`deploy.sh`는 기본 시드만 실행).

### 알려진 제한

- **서버 측 주소 → 좌표 변환(지오코딩)은 아직 구현하지 않았습니다.** 현재 매물·단지·중개사무소 등록 시 위도·경도를
  함께 받습니다. 프론트 단계에서 네이버 지도 SDK로 좌표를 얻거나, 서버 지오코딩 클라이언트를 추가할 예정입니다
  (`NAVER_MAP_*` 키 자리는 이미 마련됨).
- 알림은 **앱 내 알림만** 있습니다(SMS·이메일·알림톡 발송 없음, 운영자 결정). 외부 발송은 나중에
  `NotificationDispatcher` 구현을 추가하면 됩니다.
- 실거래가 동기화는 **아파트 매매·전월세**만 대상입니다(오피스텔·연립·단독·토지 실거래가는 미포함).
- 단지-실거래가 매칭은 국토교통부 단지 코드(aptSeq) → 법정동+지번 → 단지명 순으로 하며, 애매하면 매칭하지 않습니다.
  매칭이 안 되는 단지는 관리자 화면에서 단지의 국토교통부 코드(`externalCode`)를 입력해 주면 다음 동기화부터 연결됩니다.
- 디자인 시안(`design/`)에 남아 있던 Apple 로그인 표시(관리자 대시보드의 연동 아이콘, 미사용 스타일)는 제거했습니다.
  저장소 밖의 다른 시안 사본이 있다면 그쪽도 확인이 필요합니다.
- 테스트 환경 참고: 이번 검증용 컨테이너는 외부 HTTPS가 인증서를 다시 서명하는 프록시를 거치기 때문에,
  `deploy.sh`가 `house` 사용자로 새 패키지를 내려받을 때 인증서 오류로 pnpm이 재시도를 반복하며 멈췄습니다
  (배포는 전환 전에 안전하게 중단되고 기존 버전 유지). 패키지를 미리 받아 둔 뒤 재배포는 성공했습니다.
  일반 VPS에서는 이런 프록시가 없으므로 해당하지 않지만, 회사망 프록시 뒤 서버라면 Node에 CA 인증서 설정이 필요합니다.
