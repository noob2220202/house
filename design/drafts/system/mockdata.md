# BRAND 공통 목업 데이터 (가상)

모든 화면이 같은 숫자를 쓰도록 맞춘 샘플 데이터입니다. 단지명, 중개사무소명, 인명, 도로명 주소는 모두 **가상**입니다. 실제 회사나 단지 이름은 쓰지 않습니다.
기준일은 2026-11-23, 지역은 전라남도 순천시입니다. 가격 표기: 억/만 (예: 4억 4,500), 월세는 보증금/월세 (500/42), 층은 저·중·고/총층.
매물 수 4칸은 **분양 / 매매 / 전세 / 월세** 순서입니다. 여러 중개사가 같은 매물을 올려도 1건으로 셉니다(공동중개).
