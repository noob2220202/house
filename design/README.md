# Design drafts

Approved hi-fi design drafts (direction "B · Crisp Blue") and the design system the frontend implements.

- `drafts/project/*.dc.html` — one static artboard per screen (open in a browser, or render with `node tools/design-shot.mjs <file> <width> <out.png>`).
  `Dir{A,B,C}-*` are the three explored directions; B was chosen.
- `drafts/system/` — `system.css` (tokens + component classes), `snippets.html` (header/footer/admin shell/icons/map), `mockdata.md` (fictional Suncheon sample data), `fonts-link.html`.
- `shots/` — reference screenshots at 1440px (desktop) and 390px (mobile).

All names, complexes, agencies and prices in the drafts are fictional sample data.
The brand name is a placeholder ("BRAND").
